# IssueLine UI

Frontend application built with React + Vite.

## Run locally

From repository root:

```bash
# Frontend dev server
npm run dev

# Root start command (currently alias of dev)
npm run start
```

From inside `ui/`:

```bash
npm run dev
```

Use `npm run dev` for day-to-day development (HMR). `npm run start` is provided at root level and currently maps to the same frontend dev flow.
