1. Requisits previs

  • Node.js 24 LTS. El repositori fixa v24.16.0 a .nvmrc; si tens nvm, executa nvm use.
  • Dependències instal·lades: npm install (arrel), npm --prefix backend install.
  • Fitxer .env amb SUPABASE_URL i SUPABASE_SERVICE_ROLE_KEY.
  • Per scripts GCD: GCD_BASE_URL i opcionalment credencials (GCD_USERNAME/GCD_PASSWORD o GCD_SESSIONID).
  • Per sync:gcd manual: GCD_ALLOW_MANUAL_SYNC=true.

2. Índex ràpid de comandes

Des de l'arrel del repositori:

npm run seed:superheroes
npm run import:gcd
npm run import:gcd:issue
npm run import:collected-edition
npm run link:collected-edition-issues
npm run upload:collected-cover -- --collected-id=<uuid> --file=<ruta>
npm run verify:prod
npm run supabase:start
npm run supabase:stop
npm run supabase:status

3. Scripts de dades de personatges

3.1 seed:superheroes

Sincronitza personatges de SuperHero API cap a public.superheroes.

npm run seed:superheroes -- --ids=1,70,100
npm run seed:superheroes -- --search=batman,ironman
npm run seed:superheroes -- --names="Batman,Doctor Strange"

Opcions:

  • --ids=... llista d'IDs.
  • --search=... termes de cerca.
  • --names=... cerca per nom.
  • -h, --help ajuda.

4. Scripts d'importació GCD

4.1 import:gcd (sèrie, interactiu)

npm run import:gcd
npm run import:gcd -- --hero-slug=doctor-strange
npm run import:gcd -- --hero-api-id=122

Paràmetres:

  • --hero-slug=<slug>
  • --hero-api-id=<integer>

Flux interactiu: ID sèrie GCD, filtre de variants, cobertes disponibles i carpeta de cobertes.

4.2 import:gcd:issue (issue única)

npm run import:gcd:issue
npm run import:gcd:issue -- --hero-slug=doctor-strange --issue-id=29379 --timeline=y --covers=n

Paràmetres:

  • --hero-slug o --hero-api-id (no tots dos).
  • --issue-id (ID o URL /issue/<id>/).
  • --timeline=y|n
  • --covers=y|n
  • --covers-folder=<carpeta>

5. Scripts de recopilatoris (collected editions)

5.1 import:collected-edition

npm run import:collected-edition

Flux: demana issue GCD, mostra previsualització, detecta duplicats, permet triar heroi i confirma importació.

5.2 link:collected-edition-issues

npm run link:collected-edition-issues
npm run link:collected-edition-issues -- --collected-id=<uuid> --mode=number --issues=110-111,114 --note="Arc principal"
  • --collected-id=<uuid>
  • --mode=gcd|number
  • --issues=10,11,20-25
  • --note="..."

5.3 upload:collected-cover

npm run upload:collected-cover -- --collected-id=<uuid> --file=C:\covers\omnibus.jpg

Opcions:

  • --bucket=<nom> (defecte: collected-edition-images)
  • --prefix=<prefix> (defecte: covers)
  • --no-overwrite

Formats admesos: jpg, jpeg, png, webp, gif. Límit: 10 MB.

6. Scripts avançats de sincronització

6.1 sync:gcd (batch manual)

npm --prefix backend run sync:gcd -- doctor-strange 824 --batch=12 --delay=65000

Sintaxi:

node ./scripts/gcd-series-sync.mjs <hero-slug> <series-id> [opcions]
  • --batch, --delay, --offset
  • --issue-start, --issue-end
  • --direct-only, --include-newsstand, --skip-newsstand
Requereix GCD_ALLOW_MANUAL_SYNC=true.

6.2 link:issue-covers

npm --prefix backend run link:issue-covers
npm --prefix backend run link:issue-covers -- --apply --verbose

Sense --apply és dry-run.

7. Verificació de producció

PROD_FRONTEND_URL=https://<frontend> PROD_BACKEND_URL=https://<backend> npm run verify:prod

Comprova: salut backend, CORS i HTML principal del frontend.

8. Gestió Supabase local

npm run supabase:start
npm run supabase:stop
npm run supabase:status

9. Errors habituals

Missing required environment variable

Revisa el .env i executa les comandes des de l'arrel del repositori.

Límit de peticions GCD

  • Augmenta --delay.
  • Redueix --batch.
  • Configura credencials/sessió GCD.

Use either --hero-slug or --hero-api-id, not both

Passa només una de les dues opcions.

Invalid --issues value

Usa format vàlid: 10,11,20-25.

10. Bones pràctiques

  • Prova primer en dry-run quan sigui possible.
  • Guarda el log de consola en imports llargs.
  • Importa per trams (--issue-start/--issue-end) per facilitar reintents.
  • Després d'importar, valida l'endpoint /hero-timelines/:slug i la UI.
